# Customer Segmentation using K-Means Clustering

## 📌 Project Overview

This project implements the **K-Means clustering algorithm** on the **Wholesale Customers Dataset** to segment retail customers based on their purchasing behavior.

The project also uses the **Elbow Method** to determine an appropriate number of clusters and visualizes the customer segments.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## Features

- Load Wholesale Customers Dataset
- Data preprocessing
- Feature scaling using StandardScaler
- Determine optimal clusters using the Elbow Method
- Perform K-Means clustering
- Visualize customer segments
- Display cluster statistics
